# -Desafio-CSS-TechNews-Today 🌎

O **TechNews Today** é um portal de notícias moderno desenvolvido como parte de um desafio prático de desenvolvimento web frontend. O projeto simula uma interface de portal tecnológica utilizando técnicas modernas de estilização e layout, com foco em performance e código limpo.

## 🚀 Tecnologias e Recursos Utilizados

O projeto foi construído seguindo critérios rígidos de desenvolvimento, **sem o uso de frameworks ou JavaScript**, utilizando:

* **HTML5 Estrutural:** Marcação limpa e sem alterações na estrutura base fornecida.
* **CSS Grid Layout:** Alinhamento responsivo para posicionar o vídeo institucional e a área de newsletter lado a lado.
* **Glassmorphism:** Efeito de vidro fosco no cabeçalho utilizando a propriedade `backdrop-filter`.
* **Gradientes CSS:** Títulos estilizados com degradê moderno (`background-clip: text`).
* **Position Sticky:** Cabeçalho fixo no topo da página durante a rolagem (scroll).
* **Media Queries:** Design totalmente responsivo e adaptado para telas de celulares 📱.
* **Código Ultra-Otimizado:** Todo o estilo foi desenvolvido respeitando o limite máximo de **50 linhas de CSS**.

## 📂 Estrutura do Repositório

O repositório é público e contém apenas os arquivos essenciais do projeto:
* `desafio10a.html` — Estrutura e conteúdo do portal de notícias.
* `10a_desafio.css` — Estilização, efeitos visuais e regras de responsividade.

## 🛠️ Como Visualizar o Projeto

1. Clone este repositório ou baixe os arquivos.
2. Certifique-se de que os arquivos `desafio10a.html` e `10a_desafio.css` estejam na mesma pasta.
3. Abra o arquivo `desafio10a.html` em qualquer navegador web de sua preferência.
